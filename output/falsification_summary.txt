Honest reading:
  The full spectrum of a sigma-symmetric model is a superposition of
  two sectors and lands near 0.42; it is never GUE. A single sector
  reaches GUE only when the input blocks are GUE, i.e. by
  inheritance, so the model demonstrates that the construction CAN
  carry GUE statistics, not that it produces them.

  Read on a single sigma-sector instead of the full spectrum:
    class goe: sector+ 0.5252 .. 0.5396, sector- 0.5248 .. 0.5370
    class gue: sector+ 0.5927 .. 0.6092, sector- 0.5927 .. 0.6084
  The GOE class reads 'inconclusive' on the full spectrum because the
  full spectrum is mixed by construction, not because the model is
  unidentified: its sectors are GOE, and the GUE class's are GUE.

This is numerical evidence about a model. It is not evidence for or
against the Riemann hypothesis, which is open.
